# Test a Castia agent

Try the Castia agent in this repository and report evidence.

Start local. Run the smallest test or eval that proves the agent handles the
main scenario. If a Castia canvas or local chat surface exists, use it after
tests pass and record one short transcript.

Do not provision, deploy, publish to Teams, or grant permissions unless I
approve that action in this session.

Report:

- The command you ran.
- The result.
- One successful prompt and response.
- One failure or edge case if the repo has data for it.
- The next blocked step, if any.
