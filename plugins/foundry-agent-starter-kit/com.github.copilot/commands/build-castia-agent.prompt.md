# Build a Castia agent

Build the smallest useful Castia agent for this repository.

Read the repo instructions, README, tests, and sample data first. Then create
or update the local agent so it handles the main scenario in this repo.

Use Castia as the SDK. Do not edit Castia itself unless this repository is the
Castia monorepo.

Keep cloud work gated. Do not provision Azure resources, deploy to Foundry,
publish to Teams, grant permissions, or spend money unless I approve that
action in this session.

When you finish, report:

- The files changed.
- The local command to run the agent.
- The test or eval command and result.
- Any Foundry project, model deployment, Teams, or permission details still needed.
