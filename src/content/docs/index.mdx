## Start with the Copilot path

The fastest demo path is a focused scenario repo. Castia stays here as the reusable SDK, specs, prompts, and skills. The scenario repo owns the data, tests, and one clear agent job.

```powershell
uv add --prerelease=allow "castia[deploy,optimize,test]"
New-Item -ItemType Directory -Force .github\prompts, .github\skills
```
