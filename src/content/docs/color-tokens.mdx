## Usage

Use `--castia-accent` for primary links and buttons. It maps to Foundry azure. Use `--castia-ribbon` only for hero art, primary calls to action, and the Castia mark context.

Use the Castia tokens for actions. Keep red and rose out of primary actions so the site feels like the same product as the mark.
